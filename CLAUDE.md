# Shared project guidelines

Before making changes in this repository, read the public operating charter:
https://mu-th-ur.vercel.app/guidelines.html

The same charter is available locally at `web/guidelines.html` when offline. It
defines the shared workflow for the human and all coding assistants, including
the dashboard's role as handoff authority, privacy boundaries, validation, and
handoff publishing requirements. If an instruction here conflicts with the
human's latest direct instruction, follow the human.
